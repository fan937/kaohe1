# 板载硬件资源说明
主控型号:STM32F103C8T6，Flash：64KB，RAM：20KB 
晶振:外部高速晶振 8MHz；系统主频配置为 72MHz 
下载口:SWD下载调试；接线：PA13(SWDIO)、PA14(SWCLK)、搭配GND、3.3V
LED:PB0，低电平点亮 
按键:PA0，按下接地，浮空上拉
串口:USART1，TX:PA9，RX:PA10，波特率：115200

## 测量说明
 测量方式：丝印标识 + 万用表通断档测量
 LED：阳极接3.3V,阴极经过限流电阻接到PC13，所以低电平亮
 按键：一端PA0,一端GND；未按下时浮空,按下时接地,配置GPIO上拉输入
 串口：USART1,TX:PA9,RX:PA10,波特率：115200

 ## 主频计算
 HSE = 8MHz
 PLL倍频 = 9
 分频 = 1

 ## 串口波特率分频系数计算
 波特率：115200
 过采样：16倍
 USARTDIV = f_clk / (16 * baudrate) = 72000000 / （16 * 115200）= 39.0625，
 实际baud = 72000000 / (16 *39) ≈ 115384.62
 取整分频39，误差 = (115384.62 -115200) /115200 * 100% ≈ 0.16%

## 按键消抖
放在主循环中，按键信号变化慢，通过主循环轮询即可侦测变化，不需要额外调用中断资源，并且可以和功能模块放在一起，代码更简单，还不需要担心多次抖动的情况。

## 功能A
按一下亮、再按一下灭。如果是用中断，抖动会多次触发，这种情况中断需要加定时器避免，延时进行二次检测。
