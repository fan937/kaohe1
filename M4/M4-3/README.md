## 1
1. PWM频率选了多少？太低会怎样？太高会怎样？
选用 10kHz。频率太低：落在人耳听觉范围，电机啸叫、噪声大；开关间隔长，电流上下摆动幅度大，电流纹波大，低速抖动、调速线性变差。频率太高：MOS管频繁开关，开关损耗变大，驱动芯片发热加剧；过高还会增加单片机负担、EMI干扰上升，向外辐射杂散电磁波。
2. 测速更新率与控制周期（10ms）是什么关系？测速慢于控制会引入什么？
理想：测速更新周期 = PID控制周期（10ms），每一次PID计算都拿到最新的转速，无额外延迟。
如果测速更新慢于控制周期：PID多次循环使用同一个旧转速数据，引入测量延迟，带来相位滞后，会出现该加速时在减速，减速时加速的情况，电机的速度环容易震荡、超调、不稳定。
## 2
1.位置式PID：输出是完整的控制量（PWM绝对值），积分项保存在PID内部，每次计算直接输出最终控制值；增量式PID：输出是控制量的变化量Δu，只输出本次和上次的差值，积分累加需要放到外部。适合带积分的：位置式PID.理由：位置式自带积分存储，积分逻辑在PID内部，实现简单；增量式积分在外层，容易出现积分丢失、积分漂移问题。
2.10ms,用DWT定时器测量两次PID计算间隔。

1.比例控制输出：
u = K_p e = K_p(v_{set}-v_{real})
电机稳态运行时，需要一个固定控制输出 u_0 来克服摩擦力与负载力矩，才能维持转动。
稳态时 u=u_0，代入得：
u_0 = K_p(v_{set}-v_{real})
e_{ss}=v_{set}-v_{real}=\frac{u_0}{K_p}>0
若偏差 e=0，控制输出 u=0，电机无法克服负载，会减速停下。因此纯比例控制一定存在稳态误差。
2.减小Ki,减弱积分作用，降低积分带来的过充，增加微分D，根据误差变化率输出阻尼，抑制快速增长。积分分离：误差大的时候关掉积分，只开比例，误差小于阈值内再开积分。
3.有明显体现。pwm出现尖锐脉冲，选用Kd比较小，微分放大噪声效果不突出.
