3.采用周期法和测频率法混合测速的方案，设置一个转速阈值，高于阈值为高速情况，继续用测频率法，高速情况下脉冲数量多，量化误差小，
低于阈值为低速情况，用周期法。
## (2)
1.选用加速度量程 ±2 g，陀螺仪量程 ±250 °/s。智能车正常行驶、过弯时加速度和角速度都比较小，该量程下传感器分辨率最高；如果量程选得更小，遇到颠簸、急转向容易饱和削顶；如果选用更大量程，同样的噪声对应的角度误差会变大，分辨率下降，不利于姿态融合。
2.采用400 kHz。相比 100 kHz，更高通信速率减少传输耗时，可以提升姿态采样刷新率，降低控制延迟，适合智能车高速控制场景；
3.有校验。初始化时读取 WHO_AM_I（地址 0x75），判断返回值是否为 0x68；如果不匹配，判定传感器接入异常，程序进入阻塞。
## (3)
1.阿尔法=滤波时间常数/（滤波时间常数+dt），滤波时间常数我定为0.5s，阿尔法越靠近 1，陀螺仪权重更大，抑制加速度噪声，但陀螺漂移会体现出来；阿尔法越小，加速度仪权重更大，静态不容易飘，但运动时容易被加速度干扰。
2.陀螺仪：测角速度，短时间精度很高；但是本身存在零偏，每一次积分都会叠加这个固定误差，时间拉长，积分出来的角度会慢慢偏移（漂移），没有自校正能力。加速度计靠重力解算角度，长期来看，静止时角度是无偏的，可以用来“拉回”陀螺；但是只要有运动、冲击、离心加速度，它就混进额外加速度，瞬时噪声大、动态不准。低频段采信加速度计（抑制长期漂移），高频段采信陀螺仪（动态响应好），二者刚好互补。
3.加速度计解算姿态的前提是传感器受到的合加速度只有重力。一旦存在额外的线加速度，加速度计无法区分运动加速度和重力，就将额外加速度误以为是重力分量，导致失准。

## （4）
初为0.023度，末为0.0834度，总漂移等于0.811度，漂移率为0.811度每分钟。
1.我的零偏是2.353 dps,将MPU6050静止放稳，程序循环采集100次陀螺仪原始ADC采样值，累加后求原始值平均值，再除以陀螺灵敏度系数131，换算为角速度单位，得到零偏bias。后续读取陀螺角速度时减去该bias做补偿。
2.补偿后：陀螺静态角速度被抵消，60s纯陀螺积分总漂移很小，漂移率≈0.8 °/min。不补偿：陀螺一直带着2.353 °/s的偏移积分；
理论计算：2.353 × 60 = 141.18° / 60秒，60秒后角度会飘一百多度，漂移率≈141.18 °/min。
3.陀螺零偏的温漂：我们上电标定的bias只适合标定瞬间的温度，实验过程中芯片温度缓慢变化，零偏会缓慢变化，上电一次性的固定补偿无法跟随温漂；加速度计噪声、小幅扰动：互补滤波依赖加速度计提供长期姿态基准；加速度计有噪声、微小震动，会给姿态引入缓慢的误差，慢慢积累，带来缓慢漂移。
差异：纯陀螺仪存在随机噪声和温漂，积分随时间累加，角度单向持续漂移。互补长时间用加速度计的角度校正陀螺仪积分值，防止误差累积。改善：角度漂移率，抑制误差累积，保留陀螺仪响应快的优点。
